# Android 2.0.1 批量操作修复

- 回收站补回多选、全选/取消全选、批量恢复、批量彻底删除；彻底删除前确认。
- 部分成功显示实际完成数量，刷新后保留未完成项的选择；请求失败显示错误。
- 修复照片页取消选择后第二排批量工具栏未收起。
- 修复私密文件夹批量移出仍发送移入请求，并统一按钮、确认框和完成提示的方向。
- 文件夹批量修改使用选择快照，并通知照片列表刷新。

验证：同签名构建成功；真机使用模拟数据通过多选、全选/取消全选、部分恢复、请求失败、删除取消、批量删除、空列表，以及文件夹移入/移出测试。真机实际照片页检查批量按钮和取消选择；未对真实照片执行删除测试。

核对：照片/相册内容/人物结果/私密照片共用批量工具栏，保留删除、收藏、推送、打包及私密移动；文件夹保留多选删除、共享、私密移动。网页端照片、文件夹、回收站批量入口和处理函数仍在。照片页全选仅覆盖已加载的照片。
